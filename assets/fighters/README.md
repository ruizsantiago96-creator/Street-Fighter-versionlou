# Sprites de lucha clásica

Generados para este proyecto con la herramienta integrada `image_gen`, con fondo transparente. No requieren descargas al ejecutar el juego.

Cada PNG contiene una cuadrícula 4 × 2: reposo, paso, puñetazo, guardia, patada, agarre, especial y reacción al impacto. El cargador recorta la transparencia, conserva la escala relativa y ancla los pies. Las animaciones usan estas poses, interpolación, rotación y los efectos de cada operador.

No son recursos oficiales del juego original. El motor EEO mantiene sus propias paletas y reglas.
